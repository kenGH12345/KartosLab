# 9宫格强制屏幕适配方案

> **spec 版本**：v1.0（2026-08-07 · 回溯建档 · 需求已实现完成）
> **性质**：通用布局基础设施重构 · 项目级强制约束
> **优先级**：P0（用户明确"公共通用方案 · 所有 sim 都要支持 · 强制要遵守"）
> **关联规则**：`.codebuddy/rules/80-phet-sim-checklist.mdc` §七 L0-4（阻塞级）

## 背景

- 各 sim 屏幕布局各自为政：clamp 固定尺寸（sound）、纯 CustomPaint 铺满、手动 Column 纵向堆叠，无统一屏幕适配方案
- 用户要求：屏幕划分为 3×3 九宫格，中间格放实验画面，周边 8 格贴屏幕边缘自适应
- 目标：一套统一、强制、可复用的屏幕适配基础设施

## 方案（NineGridLayout）

**路径**：`lib/common/widgets/nine_grid_layout.dart`

尺寸规则（非等分）：

| 要素 | 规则 |
|---|---|
| 中间格（第 5 格） | **面积 ≥ 70% 屏幕**（`centerAreaRatio` 默认 0.7 · 宽、高各取 `sqrt(面积比)`≈0.837 屏 · 边条各≈8%） |
| 下限强制 | `kMinCenterAreaRatio = 0.7` · 传值 < 0.7 自动抬升（clamp 0.7~0.9025） |
| 周边 8 格 | 贴各自屏幕边缘 · 均分剩余空间 · 内容为信息展示 + 交互控件混合 |
| 尺寸自适应 | 全部格子随视口自动计算 · 无硬编码像素 · 无 `Positioned` 绝对定位 |

格子内容约定：各格内容用 `LayoutBuilder` 读取格子实际尺寸自适应渲染（组件只分格，不约束内容尺寸）。

## AC（验收标准）

### AC-1 · 通用组件（✅ 已通过）

- `NineGridLayout` 中间格**面积 ≥ 70%** 屏幕，`centerAreaRatio` 默认 0.7，下限 0.7 强制 clamp
- 8 周边格贴各自屏幕边缘、均分剩余空间
- 无 `Positioned` 绝对定位、无硬编码像素尺寸（`grep "Positioned(left:\|SizedBox(width: 800"` 应无布局违禁）
- 证据：`test/common/nine_grid_layout_test.dart` **6/6 通过**（面积 70% 精确断言 / 贴边 / 600×300 自适应 / 下限强制 / 自定义 0.8 / 空边格）

### AC-2 · 规则强制（✅ 已通过）

## 决策记录

| # | 决策点 | 结果 | 备注 |
|---|---|---|---|
| D1 | 9宫格等分 vs 非等分 | 非等分 | 用户否决等分 v1 |
| D2 | "中间 ≥70%"含义 | **面积 ≥ 70%** | 用户澄清（曾误实现为宽高各 70%） |
| D3 | 周边格内容 | 信息 + 交互混合 | 各 sim 自行决定 |
| D4 | 迁移范围 | 全部 7 sim 立即迁移 | 用户拍板 |
| D5 | 规则落地 | 写入 L0-4 阻塞级 | 用户拍板 |

## 不做

- 不改各 sim 的物理/渲染逻辑（painter 行为、模型、求解器）
- 不改配色 / 交互文案 / 场景配置
- 不实现 grid 的拖动调整（各格固定比例 · 无用户拖拽改格）
- 不迁移 `home_screen.dart`（主菜单不属于 sim 实验屏 · 其自身 overflow 归 req-home-screen-overflow-fix 管）
- 不处理 forces_scenario_test 超时（既有环境问题 · 另立诊断需求）
