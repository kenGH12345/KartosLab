## 1. 背景与目标

### 1.1 背景

Molarity（摩尔浓度）是kratos Flutter 项目的**第8 个 sim**，也是**首个化学模块**。蓝本来自 PhET Java（24文件），属于 Wave B shortlist Top-3（4.05分），是最小蓝本之一。

### 1.2 核心诉求

将 PhET Java 的 Molarity sim忠实复刻为 Flutter 版，保持化学原理正确性（C = n/V ·饱和浓度封顶 · 超饱和形成沉淀），同时遵守 kratos 项目四原则（MVC /组件化 / 通用化/ 配置化）与 EDD v2.0 规范。（S15, S16）

### 1.3 业务价值

-建立化学模块首个标杆 sim，验证现有 common 组件对化学实验的适配性
- 9溶质数据驱动的配置化方案，为后续化学 sim 提供复用范式

## 2. 功能范围（单屏）

本sim 仅一个屏幕（单Module），不含子屏切换。（S1, S5）

### 2.1 功能点清单

| # | 功能点 | 说明 | 来源 |
|---|---|---|---|
| F1 | **溶质选择** | 从 9 种溶质中选择当前溶质（ComboBox） | S1, S5 |
| F2 | **溶质量滑块** | 调节soluteAmount（0–1 mol · 默认 0.5） | S1, S10 |
| F3 | **溶液体积滑块** | 调节 volume（0.2–1 L · 默认 0.5） | S1, S10 |
| F4 | **烧杯可视化** | 3D 圆柱烧杯 + 刻度线(½L / 1L) + 底部弧线 + 标签(化学式+浓度) | S9|
| F5 | **溶液圆柱体** | 体积→高度线性映射 · 浓度→ColorRange 淡到深插值 | S6 |
| F6 | **沉淀粒子** | 粒子数 = particlesPerMole × precipitateAmount · 随机椭圆分布烧杯底 | S7 |
| F7 | **饱和指示** | 当 precipitateAmount > 0 时显示 "Saturated!"标签 | S5 |
| F8 | **浓度条** | 渐变色竖条 + 箭头指针(当前浓度) + 饱和线灰段 + qualitative(Zero/High)/quantitative(数值)双视图 | S8 |
| F9 | **Show Values 开关** | 切换 qualitative ↔ quantitative 视图（影响滑块标签/浓度条/烧杯刻度标签） | S5, S10 |
| F10 | **Reset All** | 重置全部状态到默认值 | S5 |
| F11 | **物理模型** | concentration = min(饱和浓度, n/V)；precipitateAmount = max(0, V×(n/V − 饱和浓度)) | S2 |

## 3. 验收标准（AC）

### AC-1.x ·物理模型

| AC | 验收条件 | 来源 |
|---|---|---|
| AC-1.1 | concentration = min(solute.saturatedConcentration, soluteAmount / volume)，与蓝本公式一致 | S2 |
| AC-1.2 | precipitateAmount = max(0, volume × (soluteAmount/volume − saturatedConcentration))，超饱和部分正确析出 | S2 |
| AC-1.3 | isSaturated = (precipitateAmount > 0)，用于驱动 "Saturated!" 指示 | S2 |
| AC-1.4 |当 soluteAmount = 0 时，concentration = 0，precipitateAmount = 0 | S2 |
| AC-1.5 | 切换溶质时饱和浓度随之改变，但 soluteAmount/volume 保持不变 | S1, S2 |
| AC-1.6 | 数值精度：浓度显示 2 位小数（VALUE_DECIMAL_PLACES = 2） | S12 |
| AC-1.7 | 浓度显示范围 0 – 5.0 M（min(soluteAmount)/max(volume) = 0 · max(soluteAmount)/min(volume) = 5.0） | S1|

### AC-2.x · 交互行为

| AC | 验收条件 | 来源 |
|---|---|---|
| AC-2.1 | 拖动溶质量滑块 → soluteAmount 实时更新 →溶液颜色深浅 +沉淀粒子数即时响应 | S10, S6, S7 |
| AC-2.2 | 拖动体积滑块 → volume 实时更新 → 溶液高度 + 浓度条指针即时响应 | S10, S6, S8 |
