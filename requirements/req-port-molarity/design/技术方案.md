## 2. 架构分层（MVC + 配置化四原则）

遵循 `docs/knowledge/kratos/architecture/design-patterns.md` 四原则（MVC / 组件化 / 通用化 / 配置化）与 `shared-abstraction-plan.md` §七 门禁。

```
┌──────────────────────────────────────────────────────────────┐
│  Model（纯数据 + Derived 计算）                                │
│   Solute / Solvent / Solution / MolarityState                │
└───────────────────────────────┬──────────────────────────────┘
                                │ 读（ChangeNotifier / Listenable）
┌───────────────────────────────▼──────────────────────────────┐
│  Controller（场景/流程编排 · 无 UI）                           │
│   MolarityScenarioManager (extends ScenarioManagerBase)      │
└───────────────────────────────┬──────────────────────────────┘
                                │ loadScenario → 建 MolarityState
┌───────────────────────────────▼──────────────────────────────┐
│  View（只读 state · 绘制 + 交互回调）                          │
│   MolarityScreen(NineGridLayout) + 4× CustomPainter + widgets│
└───────────────────────────────┬──────────────────────────────┘
                                │ onChanged 回写
┌───────────────────────────────▼──────────────────────────────┐
│  回到 Model 的 Intrinsic 参数 → 触发 Derived 重算              │
└──────────────────────────────────────────────────────────────┘
```

**分层契约**（对齐 design-patterns.md §一）：

| 角色 | 职责 | 约定 | 代码位置 |
|---|---|---|---|
| Model | 持有 Intrinsic 参数 · 计算 Derived · `ChangeNotifier` | `Solution` extends ChangeNotifier · `Solute/Solvent` @immutable 不可变 | `lib/chemistry/molarity/model/` |
| Controller | 加载 scenario JSON → 建 Model · 判 successCriteria | 继承 `ScenarioManagerBase` · 无状态 | `lib/chemistry/molarity/config/` |
| View | 只读 Model · CustomPainter 绘制 · 交互回调抛给上层 | Stateless / CustomPainter · 不反向依赖 Model | `lib/chemistry/molarity/view/` |

**组件化**：一元件一 Painter（Beaker / Solution / Precipitate / ConcentrationBar 各自独立 CustomPainter），对齐蓝本 4 view 元件分工。

**配置化**（§C1-§C3 强制）：
- §C1 启动路径：`MolarityScreen.initState` → `ScenarioManager.loadScenarios()` → `loadScenario(id)` → 建 state，禁止硬编码 `_state = const MolarityState(...)`
- §C2 元件规格：soluteAmount/volume 的 min/max/step/default 从 scenario JSON `paramRanges` 段读取；9 溶质数据从 `solutes` 段读取
- §C3 AI 可生成：`docs/prompts/molarity_scenario.md` + `schemas/molarity_scenario.schema.json` + ≥3 sample

// model/solute.dart
@immutable
class Solute {
  final String name;                 // 显示名（i18n key）
  final String formula;              // 化学式（含下标）
  final double saturatedConcentration; // M
  final Color solutionColorMin;      // 低浓度色
  final Color solutionColorMax;      // 高浓度色（饱和）
  final Color particleColor;         // 沉淀粒子色（KMnO₄=黑 例外）
  final double particleSize;         // 默认 5
  final int particlesPerMole;        // 默认 200
  const Solute({...});
}

// model/solvent.dart
@immutable
class Solvent {
  final String formula;   // 'H₂O'
  final Color color;      // 0xFFE0FFFF
  const Solvent({this.formula = 'H₂O', this.color = const Color(0xFFE0FFFF)});
}

// model/solution.dart  —— 化学正确性核心
class Solution extends ChangeNotifier {
  Solvent solvent;
  Solute solute;              // Intrinsic P1
  double soluteAmount;        // Intrinsic P2 (mol)
  double volume;              // Intrinsic P3 (L)

  // --- Derived（getter 计算 · 严禁独立字段）---
  double get concentration => volume > 0
      ? math.min(solute.saturatedConcentration, soluteAmount / volume)
      : 0;
  double get precipitateAmount => volume > 0
      ? math.max(0, volume * (soluteAmount / volume - solute.saturatedConcentration))
      : soluteAmount;
  bool get isSaturated => precipitateAmount > 0;
  int get numberOfParticles {
    final n = (solute.particlesPerMole * precipitateAmount).floor();
    return precipitateAmount > 0 && n < 1 ? 1 : n;  // 至少 1 个粒子
  }
  Color get solutionColor {
    if (concentration <= 0) return solvent.color;
    final t = (concentration / solute.saturatedConcentration).clamp(0.0, 1.0);
    return ColorRange.interpolate(solute.solutionColorMin, solute.solutionColorMax, t);
  }

  // setters 触发 notifyListeners（供 View 回写）
  set setSolute(Solute v) {...; notifyListeners();}
  set setSoluteAmount(double v) {...; notifyListeners();}
  set setVolume(double v) {...; notifyListeners();}
}

// model/molarity_state.dart
class MolarityState {

  bool valuesVisible;           // Intrinsic P4

}

## 4. 数据流（状态 → Solve → Render 闭环）

本 sim **无 tick / 无 SimulationClock**（EDD §3.4 洞见 · 纯响应式）。所有 Derived 为即时数学计算。

```
用户交互（滑块/ComboBox/Checkbox）
      │
      ▼
Controller.setXxx(state) → Solution.setXxx → notifyListeners()
      │
      ▼
Solution Derived getter 即时重算（concentration / precipitateAmount / solutionColor / numberOfParticles）
      │
      ▼
MolarityScreen(AnimatedBuilder/ListenableBuilder) rebuild
      │
      ▼
4× CustomPainter 重新绘制（溶液颜色/液面高度/沉淀粒子/浓度条指针）
```

### Derived 计算时机

| Derived | 计算时机 | 触发源 | 说明 |
|---|---|---|---|
| `concentration` | **任何** solute/soluteAmount/volume 变化时 | R1/R2/R3 | `min(sat, n/V)` · volume≤0 时=0 |
| `precipitateAmount` | **任何** solute/soluteAmount/volume 变化时 | R1/R2/R3 | `max(0, V×(n/V−sat))` · volume≤0 时=soluteAmount |
| `isSaturated` | 依赖 precipitateAmount | 同上 | `precipitateAmount > 0` |
| `solutionColor` | 依赖 concentration | 同上 | ColorRange 插值 · concentration=0 → 溶剂色 |
| `numberOfParticles` | 依赖 precipitateAmount | 同上 | `int(particlesPerMole×precipitate)` · ≥1 |

> **关键**：concentration 与 precipitateAmount 是**派生量，严禁作为独立可写字段**（EDD §3.3 · D1/D2 为 getter）。View 层通过 ChangeNotifier 监听 Intrinsic 参数变化自动触发 rebuild，无需手动调度重算。

### 7.6 successCriteria 类型枚举（MolarityCriterion.check 实现）

| type | 判定逻辑 | 用于 |
|---|---|---|
| `solutionSaturated` | `solution.isSaturated` | 饱和挑战 |
| `concentrationReached` | `|solution.concentration − target| ≤ tolerance` | 定量练习 |
| `precipitateVisible` | `solution.numberOfParticles > 0` | 沉淀观察 |
