## 1. 目标

在 KARTOSLAB Flutter 中复刻 **Capacitor Lab: Basics** 双屏模拟，视觉与行为对齐原版源码；**原图优先复用**，程序绘制按 Scenery 几何重建。

---

## 2. 范围（MVP = 全功能对齐 Basics，不含 dielectric 扩展）

### 屏 1 — Capacitance
- 电池 + 电容 + 双位开关（接电池 / 开路）
- 板面积、板间距拖拽
- 条形表：电容 / 顶板电荷 / 储能
- View：板电荷、电场、电流、电流方向、条形图总开关
- 电压表工具箱
- Reset All
- **无** TimeControl / Stopwatch

### 屏 2 — Light Bulb
- 上述 + 灯泡支路（三态开关默认）
- RC 放电与灯泡亮度
- TimeControl + Stopwatch
- 灯泡侧电流指示

### 明确不做（MVP）
- DebugLayer 用户可见化
- PhET-iO
- `switch=twoState` 可作为后续；默认 threeState
- dielectric 材料（Basics 源码为真空）

## 3. Acceptance Criteria

| ID | AC | 验证 |
|----|-----|------|
| AC-01 | 双屏入口，背景色 `rgb(153,193,255)`，逻辑画布 1024×618 | 视觉 + 常量 |
| AC-02 | 默认：V=0，接电池，板尺寸/间距为 CapacitorConstants 默认，C/Q/U 与公式一致 | unit |
| AC-03 | 电压滑条 −1.5…1.5，0.05 步进，\|V\|<0.15 松手归零；极性翻转电池图形 | 交互 |
| AC-04 | 板间距/面积拖拽范围与量化与源码一致；C 实时更新 | unit + 交互 |
| AC-05 | Capacitance 开关：BATTERY ↔ OPEN；开路保持 Q，V=Q/C | unit |
| AC-06 | Light Bulb：三态；接灯时 V 按 exp(−dt/RC) 衰减，R=5e12 | unit |
| AC-07 | 电场/电荷可视化开关；场线与电荷数算法对齐 EFieldNode / PlateChargeNode | 视觉 |
| AC-08 | 三块条形表满量程 2.7e-12；显隐 checkbox 行为对齐 | 交互 |
| AC-09 | 电压表：原图 body+双探针；可拖；读数或 “?”；可收回 toolbox | 交互 + 视觉 |
| AC-10 | 电流指示可见性与电子/常规方向；fade 行为对齐 | 视觉 |
| AC-11 | Light Bulb 时间控制与秒表 | 交互 |
| AC-12 | Reset All 恢复模型 + 共享 switch cue | 交互 |

| AC-14 | 电池/板/场/线/表 **按源码几何** Canvas，非臆造 | 代码审 + 视觉 |
