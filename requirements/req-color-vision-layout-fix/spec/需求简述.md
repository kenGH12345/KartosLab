# 修复 color_vision Single Bulb 屏窄视口布局崩溃

> **spec 版本**：v1.1（2026-08-05 18:24 · 用户四问决策 β）
> **来源**：`req-verify-selftest-color-vision` 阶段 3 补测衍生发现（2026-08-05）
> **性质**：Bug 修复 · L0-2 + L0-3 违规
> **优先级**：P1（阻塞级布局规则违反 · 依 `.codebuddy/rules/80-phet-sim-checklist.mdc` §六 违反后果表）

## 现象

**触发条件**：`lib/color_vision/` sim → Single Bulb 屏 → 用户缩窄窗口宽度（约 800px 以下）→ 切换 Filter=Red

**观察结果**：主图 CustomPaint 完全消失，屏幕只剩「颜色过滤原理」知识面板 + 底部控制面板

**证据截图**：`../req-verify-selftest-color-vision/screenshots/ac-BUG-layout-overflow-red.png`（101 KB）

**对照图**（同 sim 无滤片状态正常）：`../req-verify-selftest-color-vision/screenshots/ac-2-step-1-white-nofilter.png`（297 KB）

## 根因（信心 95%）

引用 `lib/color_vision/screens/single_bulb_screen.dart:118-201`：

```dart
Column(children: [
  Expanded(flex: 5, child: CustomPaint(size: Size.infinite, ...)),  // 主图
  _buildKnowledgePanel(),                                            // ⚠️ 无高度约束
  PropertyControlPanel(...),                                         // ⚠️ 无高度约束
])
```

- 知识面板与控制面板作为 Column 的 free children，会撑到内容需要的**自然高度**
- Filter=Red 时 `KnowledgeItem.active=true`（`single_bulb_screen.dart:216`）触发额外 border/aura 渲染 → 知识面板内容高度膨胀
- 窄窗口下 `Expanded(flex:5)` 拿到的剩余空间 = `窗口高度 - 知识面板自然高度 - 控制面板自然高度` → 可能为 0 或负数 → **主图彻底消失**

## 违反的规则

依 `.codebuddy/rules/80-phet-sim-checklist.mdc` §七：

| 条款 | 现状 | 违反理由 |
|---|---|---|
| **L0-2**（响应式无溢出） | 窄视口下主图完全不可见 | "主要控件可见" 未满足 · 主图是本 sim 最核心控件 |
| **L0-3**（主图尺寸随视口缩放） | 未使用 LayoutBuilder + `side = min(viewportW×0.6, viewportH×0.7)` 保底 | 主图仅靠 `Expanded(flex:5)` 分配剩余空间 · 无 minHeight 保底 |

- **取舍成本**（用户已接受）：知识面板变为内部可滚动 · 可能需要滚动才能看全所有卡片（衍自 Q2 选项表权衡）

### AC-5（方案 B 专项）· 知识面板滚动体验

- 知识面板内部 `SingleChildScrollView` 滚动时：

  - 滚动条在窄窗口下不遮挡卡片内容

## 实现方案（v1.1 已定：方案 B）

用户 Q2 选 B · tech-leader 阶段**无需再选**，只需具体化实现细节。

### 方案 B · 知识面板 Expanded + 内部滚动

**改动点**：`lib/color_vision/screens/single_bulb_screen.dart:118-125`

```dart
// 前（现状）
Column(children: [
  Expanded(flex: 5, child: CustomPaint(...)),
  _buildKnowledgePanel(),               // free child
  PropertyControlPanel(...),            // free child
]);

// 后（方案 B）
Column(children: [
  Expanded(flex: 5, child: CustomPaint(...)),
  Expanded(
    flex: 3,
    child: SingleChildScrollView(child: _buildKnowledgePanel()),
  ),
  PropertyControlPanel(...),            // 保留 free child（高度相对固定）
]);
```

**关键约束**：
- flex 比 5:3 已预留主图 > 知识面板优先级
- `SingleChildScrollView` 确保知识面板膨胀不会涨到 Column 外层
- `PropertyControlPanel` 保持 free child（内容高度相对确定· SpectrumSlider 只在 mono 时显示· 不至于吃掉主图）

### 未选方案备注（不实施）

- 方案 A（LayoutBuilder + SizedBox 保底）：如方案 B 上线后发现“很高很窄”视口仍有问题，可补入 LayoutBuilder 作为二阶升级
- 方案 C（窄视口折叠知识面板为 Tab）：代码量大 · 本需求不采纳

## 不做

- 不改光子束渲染逻辑（`PhotonBeam` / `SingleBulbPainter`）
- 不改配色 / 交互文案
- 不改 `rgb_bulbs_screen`（用户 Q1=A：本次只修 single_bulb · rgb_bulbs 如有同类问题另立需求）
- 不改知识面板内容（卡片文案 / 颜色 / 图标）
- 不引入 LayoutBuilder（本方案 B 不需要 · 避免过度设计 · 依 `00-engineering-principles.mdc` 第 4 条最小化方案）
