## 1. 背景

本需求归档本轮全部 UI 交互优化工作（S1），涵盖从"未知到已知"的完整演进：

1. **主界面混乱** → 学科分组编排重写（已交付）
2. **各实验缺乏统一引导入口** → ExperimentIntroPanel 通用组件上抽 + 10 屏接入（已交付）
3. **molarity 实验细节打磨**（中文化 + 返回键 + 面板收回）→ 已交付
4. **optics 返回键失效**（布局崩溃导致 hit test 全局失败）→ 已交付
5. **操作面板布局不一致**（各屏 midRight/topRight 分散）→ 统一底部横排，以 molarity 试点验证（**待做**）（S1, S8）
6. **HomeScreen 1600×900 overflow 49px**（原存桩 req-home-screen-overflow-fix）→ 合并入本需求验证（S2, S7）

## 7. 验收方法汇总

1. **`flutter analyze`** — 零 error/warning
2. **`flutter test`** — 单元测试 + 集成测试全部通过
3. **视口审计** — 320 / 600 / 900 / 1200 / 1600 / 1920 六档宽度逐一无 overflow
4. **手动交互验证** — 各屏导航、引导面板、操作面板功能可达
5. **代码审查** — 布局结构符合 L0 规范
