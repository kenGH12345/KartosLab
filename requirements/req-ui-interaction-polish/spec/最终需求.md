## 1. 原始需求

本需求归档本轮全部 UI 交互优化工作（"从未知到已知"的完整演进），覆盖 6 个主题：

1. **主界面混乱** → 学科分组编排重写（物理/化学两级）
2. **各实验缺乏统一引导入口** → ExperimentIntroPanel 通用组件上抽 + 10 屏接入
3. **molarity 实验细节打磨**（中文化 + 返回键 + 面板收回）
4. **optics 返回键失效**（布局崩溃导致 hit test 全局失败）
5. **操作面板布局不一致**（各屏 midRight/topRight 分散）→ 统一底部横排，以 molarity 试点验证（AC-5）
6. **HomeScreen 1600×900 overflow 49px**（原存桩 req-home-screen-overflow-fix，合并入本需求）→ 验证是否已随重写消除（AC-6）

详细背景见 `spec/需求简述.md`，来源决策见 `spec/context/来源归档.md`。
