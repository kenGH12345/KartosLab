# 需求简述 · My Solar System

> req-id: `req-my-solar-system` · SOP: agile-vibe · EDD 模板: v2.0  
> 本文件定义**做什么 / 做到什么程度**。物理公式与文件行号见 `physics-analysis.md` / `source-analysis.md`。

## 背景与目标

将 PhET **My Solar System**（HTML5/TypeScript，本地 `1.4.0-dev.4`）迁入 KARTOSLAB Flutter。学生通过改变质量、位置、速度观察多体引力系统，Lab 屏提供全部教学 preset。

优先级：功能一致 > 交互一致 > 状态/物理一致 > 布局一致 > 动画一致 > 代码优雅。

**WHY**：补齐天体力学组的 N-body 实验（Kepler 只覆盖两体解析椭圆）。

## 范围

### 做

- Flutter 原生 UI / 状态 / CustomPainter / 手势 / PEFRL 求解 / 测试
- 两屏：**Intro**（双体）+ **Lab**（最多 4 体 + preset）
- Home：物理 → 天体力学 → 新增「My Solar System」卡片（不改 Kepler）
- 可见 Lab preset 全部可切换（见 AC-P）
- Timing：Restart / Play / Pause / Step / Fast / Normal / Slow / 年时钟 / Clear
- Return Bodies、Follow Center of Mass、Reset All
- Data：质量数字+滑条；Lab More Data 下的 x/y、Vx/Vy；Lab Bodies spinner 1–4
- 可见性：CoM、Speed、Velocity、Gravity+力缩放、Path、Grid、Measuring Tape、Zoom
- 拖拽天体位置、拖拽速度矢
- 碰撞（小体消失、动量并入大体）、越界可 Return
- NineGrid + 三视口无溢出

### 不做（有意差异，对齐 Kepler 先例）

- WebView / iframe / 原 HTML
- PhET-iO、PDOM 完整键盘、动态 locale、Projector 色表
- 自制缺失的 `pathIcon.png` / grab-release mp3（记录缺口）
- 修改 Kepler 或其他 sim / 抽 Kepler 代码进 `lib/common`（本需求期间）
- 用「合理的牛顿积分」替换 PEFRL 系数与子步结构

### 非目标（原版有、一期可降级）

- Orbital System 1–4：原版 ComboBox 默认不可见（S2 `OrbitalSystemComboBox.ts:52-55`）。数据保留，UI 默认隐藏。[决策待确认：是否露出]
- Body 循环音 / 添加删除音：资源在 solar-system-common，本机缺失 → `[BLOCKED]` 音效，静默不自制

### Physics

| ID | 标准 | 对比方法 |
|---|---|---|
| AC-Φ1 | 力：`F = G m1 m2 * (r2-r1) / \|r\|^3`（即 G m1 m2 / r² 沿 r） | 两体静止、已知间距，力矢量与手算相对误差 &lt; 1e-9 |
| AC-Φ2 | G 取 **4.45669**（见 physics-analysis：preset 圆轨道闭合；`doc/model.md` 的 4.4567e-3 为文档错误） | SUN_PLANET 圆轨道速度量级匹配 |
| AC-Φ3 | 积分：PEFRL 五步系数 XI/LAMBDA/CHI 与 `NumericalEngine.ts` 字面量一致；每 `run` 内 `iterationCount = 4000/N`；**子步内不重算力** | 单测固定 dt、2 体，位置与参考实现比对 |
| AC-Φ4 | `stepOnce`：`dt *= speed`；`n = ceil(dt*30)`；`dt /= n`；`dt *= engineTimeScale(0.05)`；循环 run+checkCollisions；`time += dt * modelToViewTime` | 单测 step 计数与 time 增量 |
| AC-Φ5 | 碰撞：重叠则质量小者 `isActive=false`；大者 `v += v_small * m_small/m_large`（动量并入，**质量不合并**） | 构造重叠两体 |
| AC-Φ6 | CoM：`r = Σ m_i r_i / M`，`v = Σ m_i v_i / M` | 单测 |
| AC-Φ7 | `followingCenterOfMass` ⇔ `\|r_com\| &lt; 1 AU` 且 `\|v_com\| &lt; 0.01 km/s` | 单测 |
