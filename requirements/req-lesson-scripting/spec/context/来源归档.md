## 关键洞察（从来源交叉分析）

1. **表达力缺口**（S1+S2+S7）：当前 scenario 体系是"单场景孤岛"——每个 JSON 描述一个独立实验，无场景间依赖/顺序/分支关系。
2. **依赖基础已在建设中**（S5+S6）：条件树（req-criteria-composable）和预测题（req-predictive-inquiry）正在落地，它们分别提供"判定能力"和"得分能力"——都是剧本分支条件的前置。
3. **AI 可生成性约束**（S3）：新增的剧本 JSON 必须符合 §C3（prompt + schema + 样本），这对剧本 DSL 的复杂度有天然约束。
4. **评估型产出**（S1）：用户明确"建议作为独立方向评估"，不在本需求直接实现 runtime。需定义评估深度和产出物。
