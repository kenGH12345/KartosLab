# PHASE5_GLOSSARY_CONFLICTS

| Term | Wrong | Canonical | Why |
|---|---|---|---|
| Normal (optics) | 普通 / 正常 | **法线** | Ray diagram normal line |
| Normal (time speed) | 法线 | **正常** | Waves Intro / Normal Modes speed |
| Phase (physics) | 阶段 | **相位** | Wave / normal-mode phase |
| Phase (UI stage) | 相位 | **阶段** | Only if non-physics UI |
| Amplitude | 幅度 (colloquial) | **振幅** | Unify with physics.* |
| Frequency | 频次 | **频率** | Scientific |
| Measurement vs Observe | 测量 / 观测 | Measure=**测量**; Observe=**观测** | Quantum Measurement UI |
| State (quantum) | UI 状态 | **量子态** / **制备态** | Not Flutter state |
| Wave vs Wavelength | 波 / 波长 | Distinct keys | |
| Photon vs Particle | 光子 / 粒子 | Context-specific | QWI uses 粒子 for single-particle |
| Collapse | — | **坍缩** only if measurement-collapse label exists | Avoid inventing |
| Polarization | 极化 (chem) | **偏振** | Optics / photon |
