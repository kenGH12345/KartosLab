# PHASE6_GLOSSARY_CONFLICTS

| Term | Wrong | Canonical | Why |
|---|---|---|---|
| element vs atom | 元素↔原子互换 | **元素** ≠ **原子** | Atomic number labels element; build-an-atom builds atom |
| molecule vs compound | 分子=化合物 | Context-specific | Molecule=分子; Compound=化合物 when distinct |
| solution | 答案 / solution (CS) | **溶液** | Chemistry only |
| base | 基 / 基底 | **碱** (acid–base); 基 only if basis/math | ABS / pH |
| bond | 连接 / 绑定 | **化学键** | Molecule shapes / polarity |
| reaction | 交互 | **反应** | BCE / RPAL |
| product | 产品 | **生成物** | Chemistry |
| concentration vs density | 浓度=密度 | **浓度** ≠ **密度** | Molarity / fluids |
| mass number vs mass | 质量数=质量 | **质量数** ≠ **质量** | Isotopes / BAA |
| atomic number | 原子数 | **原子序数** | Not “number of atoms” |
| charge vs charging | 充电 | **电荷** / 带电的 | Adjective: 带电的 |
| pH | 酸碱度 | **pH** | Keep symbol unless product requires otherwise |
| Normal (SOM speed) | 法线 | **正常** | Reuse common/fluids pattern |
| Water (substance name) | 水波 (waves) | **水** | Chemistry substance; waves keep 水波 for scene |
